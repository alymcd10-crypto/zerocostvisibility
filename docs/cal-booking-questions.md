# Cal.com booking questions: Visibility Audit

Paste these into the Cal.com event (Event Types > 1:1 Visibility Session > Advanced > Booking questions > Add a question). Keep Cal.com's default Name and Email questions, and add these after them.

| # | Question | Input type | Required |
|---|---|---|---|
| 1 | Your brokerage and the towns you sell in | Short text | Yes |
| 2 | Last 12 months: how many closings, and roughly what volume? | Short text | Yes |
| 3 | Where did that business come from? Rough percentages are fine: past clients, sphere, Zillow or paid leads, open houses, other | Long text | Yes |
| 4 | About how much do you spend on leads or ads each month? | Short text | No |
| 5 | Link to your Zillow profile | URL | No |
| 6 | Link to your Google Business Profile | URL | No |
| 7 | About how many past clients do you have a phone number for? | Number | No |
| 8 | Which local Facebook groups are you in? | Long text | No |
| 9 | What's taking your time without paying off? | Long text | No |
| 10 | If one thing changed in the next 90 days, what should it be? | Long text | Yes |

The Book page tells visitors about these questions ("When you book, you'll answer a few questions about your last year, so we start with your numbers."), so add them before the event goes live.
