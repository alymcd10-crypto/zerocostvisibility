# Cal.com booking questions: Zero-Cost Visibility Session

Paste these into the Cal.com event (Event Types > 1:1 Visibility Session > Advanced > Booking questions > Add a question). Keep Cal.com's default Name and Email questions, and add these after them. Delete any older questions on the event.

| # | Question | Input type | Required |
|---|---|---|---|
| 1 | Your brokerage and the towns you sell in | Short text | Yes |
| 2 | Links to your Zillow and Google Business profiles | Long text | No |
| 3 | What would you most like help with? (More referrals / More reviews / More repeat business / Not sure yet) | Short text | Yes |

Liz uses the answers to start the shared Google Doc before the call: the towns and profile links let her prepare your market, and question 3 decides where the hour starts.
